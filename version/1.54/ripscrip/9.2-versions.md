# 9.2 Version Identification Reference

[◀ Prev: 9.1 Text Variable Reference](9.1-text-variable-reference.md) · [Contents](README.md) · [Next: 9.3 Host Command & Control Character Reference ▶](9.3-host-command-reference.md)

Every known RIPscrip version identification string of 1.5x, with provenance. The identification phrase is what a RIP-capable terminal sends in reply to the [`ESC[!` auto-sense query](1.1-protocol-and-command-hierarchy.md#ansi-sequences-auto-sensing) and what the [`$RIPVER$`](5.1-text-variables.md#ripver) text variable returns.

## The identification phrase

`RIPSCRIPxxyyvs` — a fixed literal prefix followed by four numeric fields:

| Field | Width | Meaning                    |
| ----- | ----- | -------------------------- |
| `xx`  | 2     | Major version, zero-padded |
| `yy`  | 2     | Minor version, zero-padded |
| `v`   | 1     | Vendor code                |
| `s`   | 1     | Vendor sub-version         |

Vendor codes defined by the 1.54 specification: `0` = generic/unspecified, `1` = RIPterm, `2` = QmodemPro.

## Known 1.5x identification strings

| String | Reading | Provenance |
| --- | --- | --- |
| `RIPSCRIP015410` | v1.54, vendor 1 (RIPterm), sub-version 0 | The string embedded in the shipped RIPterm 1.54 executable (`strings` on `RIPTERM.EXE`, 1.54 distribution); also the 1.54 specification's own auto-sense worked example, and the RIPv1 reply modern SyncTERM sends (`sbbs:src/syncterm/ripper.c:7619`) |
| `RIPSCRIP015400` | v1.54, generic vendor 0 | `$RIPVER$` sample output in the 1.54 `RIPTERM.DOC` (documentation example) |
| `RIPSCRIP015300` | v1.53 | Stale `$RIPVER$` example in the 1.54 specification text itself (never updated from 1.53 — see the editor's note below), still quoted verbatim as the `$RIPVER$` example in RIPtel 3.1's help years later. Documentary evidence of the 1.53-era string; no 1.53 binary has been verified |

Earlier releases (1.50–1.52) presumably replied with their own version digits, but no identification string from those binaries has been recovered or verified.
