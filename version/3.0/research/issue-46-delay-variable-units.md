## Native fake-clock checkpoint

`run/riptel-macro-probe` now passes **3,459,218 checks**. Original registration confirms D callback0x2832d. Original callback, numeric conversion, busy-wait helper0x282ca and full expansion execute. Only the **stdcall timeGetTime import0x966fc** is substituted: each expected interval returns a start, then deadline-1, then deadline, so the exact comparison/rounding is tested without sleeping or real waiting. Zero interval returns the equal deadline on its first poll. Polls are bounded; no real GUI/audio/time delay is introduced. Existing variable-engine controls from earlier notes remain; this adds no new callback/processor hook.

Exhaustive durations **0..65536** verify `chunks=(n-1)/3900` when n>3900, remainder `n-chunks*3900`, each chunk65000ms and final `floor(remainder*1000/60)`. Total requested clock interval is exactly `floor(n*1000/60)` over this domain. Therefore **D(1) targets16ms** and **D(60) targets1000ms**; the unit is a sixtieth, with fractional milliseconds truncated. Actual wall-clock elapsed time remains subject to clock granularity/phase/scheduling; native fake time establishes target arithmetic, not an exact physical runtime.

Original D requires exactly one argument, but it does **not** enforce the draft's 1..65535 gate. Zero and65536 pass; only the first character is checked as a digit before original atoi-like prefix conversion. Native `1A`/`1.5` become1, `60x`/`00060` become60; plus/minus/blank/letter/space starts reject without clock calls. This is a shipped parser quirk, not an invitation to advertise arbitrary oversized conversions as portable protocol values. The documented ordinary input range remains separately identified. All missing/extra-argument cases reject. Full dollar expansion consumes D(1),D(60),D(0),D(65536),D(1A) into no text after synchronous polling completes.

A controlled timer start0xfffffff8 with D(1) makes deadline wrap to8; the next unsigned timer value0xfffffff9 already compares above8, so original delay returns immediately after that poll. This records the existing wrap defect rather than pretending its unsigned absolute comparison is rollover safe. Default native execution does not install any context-level asynchronous input gate or dispatch the wire3D handler: helper takes only duration, busy-polls its timer and returns on the same evaluation call stack.
