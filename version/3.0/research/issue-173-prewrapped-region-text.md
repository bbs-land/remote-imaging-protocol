## Wire, placement and advancement

- Slot **105** `1T` → **0xa529**, four current XY-width coordinates and two separate one-digit IDs. Handler orders WORLD endpoints via **0x3112e**, calls **0x3be44** at **0xa5d4**, and selects the article at **0xa5de** via **0x3c399**. Each endpoint is converted via **0x310b8** with no viewport or port offset. Column device width is **right − left + 1** at **0x3befe–0x3bf08**. Definition rewinds that article's current column to -1 and reinstates flow.
- Slot **106** `1t` → **0xd70b**, one numeric digit followed by text. The wrapper selects the active drawing DC and clip, substitutes one space for an empty string via **0x7ac50**, and calls **0x3c00a** at **0xd7ab**. It has no macro/template expansion call. Layout checks article active, non-null text, unsigned mode **0 or 1** at **0x3c033**, then checks the current column against exhaustion 36. Inactive viewport suppresses the wrapper through **0x3445b**.
- **0x3ba81** finds the next defined column owned by the selected article in increasing slot order. It initializes line count zero and device Y = top, with the dedicated stroked-font top adjustment **0x3bb2c → 0x02540(context,1)**. That helper supplies device stroke reference height minus the scaled CHR font top metric. **0x3c08c–0x3c0d7** tests `Y + A + D > bottom` and can select the next column once before drawing. A newly selected replacement column is used at its first-line position. For ordinary compatible scenes, choose each column tall enough for the first line of the current font. Do not reinterpret the missing second fit check as character-level cropping to the column.
- **0x3c0de** trims trailing whitespace. An empty result uses the space placeholder. **0x3c109** counts nonwhitespace. A blank first line in a later column is suppressed when it and the most recent earlier defined column of this article are disjoint, or the new top is at/above the earlier top. At **0x3c168–0x3c1a8** the comparisons use the stored inclusive DEVICE endpoints. An accepted line otherwise calls **0x3b471** and then **0x3bf54**, which adds the current line step, increments line count and immediately advances to next column when the next line no longer fits. On exhaustion the prewrapped branch returns without invoking the raw wrap/overflow machinery.
- Active font changes mark the article metrics dirty through **0x3c37e**, e.g. classic **0x1ca3f** and outline **0x1b03a**. **0x3c084** refreshes at layout when dirty, before the fit check. No metrics are latched by `1T`. In bitmap or extended outline modes, **0x3fc70 / 0x3fc20 / 0x3fc40** supply line step, A and D. These are distinct metrics and the step may differ from A+D. In classic stroked mode, **0x1640(context,"W",1)** supplies step, **0x2500(context,1)** supplies A and **0x25b0(context,1) − A** supplies D. The renderer uses the reference ordinate Y+A. Stroke positioning first converts that ordinate back to WORLD and subtracts the native stroke reference height at **0x3b50d–0x3b525**. Changed metrics govern the next drawing call and subsequent advance, without repositioning previously drawn lines.
- Article zero is valid even with a default `00` suffix. Draw gate at **0x3c01d** checks article active and never applies the raw route's positive-article guard. Raw input **0x3ce4e–0x3ce50** and end helper **0x3d499–0x3d49b** reject article zero. `1E` (slot **92**, **0xbdbd**) calls that end helper through **0x3bf47**. It does not deactivate article zero, so later `1t` calls still draw until exhaustion or another state change.

## Horizontal layout, cursor and clipping

- **0x3b471** strips backslashes on a forward pass via **0x654b5** before horizontal layout, independently of framing. The stripper advances after each iteration, even after deleting a byte. **0x65c0b** counts leading ASCII spaces, which force the left path in either mode. **0x65bd8** counts groups separated by ASCII space; fewer than two groups goes to the same unadjusted placement. The bitmapped/outline left reference is the stored DEVICE left coordinate. The stroke adapter starts at the stored WORLD left and converts at the stroke boundary. Legacy direction and outline string and character rotation are passed as horizontal/unrotated in the placement adapters. **0x3b0e2**, **0x3b2fb** and the two-word branches send the current font and drawing attributes to the respective renderer.
- **0x3b258** computes signed spare width as stored column width minus the measured line width. At identity scale, the full-justify fixture uses that difference directly. The original stroke metric call **0x3b295 → 0x01410(...,0)** returns the unconverted stroke width and the stroke gap is added to its private cursor, while the supplied W is device width. Bitmap/outline width uses **0x3fcd0** in device units. This historical mixed-unit stroke path at unequal scales supplies no portable ink guarantee.
- **0x3b678** divides `(spare × 256)` by `words−1` with signed truncation. For two words, add the whole spare width before the second segment. For three or more, cumulative shift before word i (first word i=0) is arithmetic shift right 8 of `i × quotient`, i.e. floor of its /256 value. Original interword ASCII spaces remain measured. Overwide strings have negative spare width in mode 1. Mode 0 and one-word mode 1 make no horizontal fit test. Neither wraps or creates a remainder.
- Wrapper **0xd78c → 0x343e4**, **0xd795 → 0x342ad → 0x03fbf** selects the surface and viewport clip. Renderer parameters include column X and Y, and no column clipping rectangle is passed to those branches. **0x34319** restores ordinary clip state. The column is a layout box. Within the active viewport and renderable surface, ink can cross its sides. The source does not add viewport left/top to the converted column coordinates. **0x1840** sets the private stroke cursor at `context+0x52`, not the graphics cursor. The bitmap/outline path submits explicit coordinates and never calls the ordinary T/TEXT_XY cursor stores. Preserve the caller's RIP graphics cursor.
