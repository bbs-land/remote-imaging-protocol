The little-endian count at `0x28` is six and directory pointer at `0x2a` is `0x3c`. Reading six 60-byte records yields 30 distinct font offsets, five per record. At each offset, the little-endian words at +34 and +36 give last code 255 and the per-glyph byte size. For each font, `offset + 50 + 255 × bytesPerGlyph` equals the next sorted offset or EOF. At `0x1d6` the first 8×11 font starts with `7E 81 A5 A5 81 81 BD 99 81 81 7E`, the stored code `0x01`. Code `0x00` is implicit, and the offset of code `c` in `1..255` is `offset + 50 + (c − 1) × bytesPerGlyph`.
