## Original wire order and native checkpoint

Physical dispatch **slot118** (logical117), level2 `s`, points to **0x468eb** with decoded fields mega1 target and mega2 flags. This investigation uses that three-character form; the broader family/reserved-field dispute in #2 is separate. Handler0x468eb–0x46999 first performs pending-input cleanup0x45038, then returns if graphics-disabled option context+0x36,+0x104 is nonzero. An unsigned target>=36 reports out-of-range and returns **before any flag write**.

For valid targets the order is explicit: source-protect bit4 at **0x46931–0x46940**, source-unprotect bit8 at **0x46943–0x46952**, select target via **0x3393c** at0x4695c, bind active device via **0x343e4** at0x46965, destination-protect bit1 at **0x4696d–0x4697c**, destination-unprotect bit2 at **0x4697f–0x4698e**. Every protection call uses **0x3378a(ctx,-1,on/off)**, so source calls refer to the old current index and destination calls to the _actual selected current index_. Selection result is ignored, with no rollback. Both per-operand conflicts resolve to **unprotect**, and destination actions occur after source actions on a same-port switch. Thus current1 `2s106` ends unprotected and `2s109` ends protected. Protection prevents redefinition/deletion, not selecting a defined port. Setter0x3378a treats slot0 as an ignored/false operation rather than writing its bit.

A more substantial inherited error: **ordinary undefined destinations do not fall back to0**. Original shared selector0x3393c finds type0 and calls actual **screen-port constructor0x3326f** with default screen size (system+0x3a−word+0x32, +0x3e−word+0x36), x/y0, screen-kind0. Successful creation selects the requested index; only failed construction sets current0 at0x33999f. Constructor protection gate **0x332d5** rejects a stale protected-but-undefined record before writing it. A defined protected screen/offscreen target selects normally. Binding0x343e4 executes unchanged and uses physical port0 DC for screen targets or that offscreen target's DC. No arbitrary failure was inserted into the original selector or constructor.
