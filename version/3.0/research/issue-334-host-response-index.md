- **Query timing.** Wire query handler `0xd3da` applies immediate mode 0. The common stored-expression helper `0x13e61` handles modes 1–6. Original click dispatch has no mode 1–4 execution path. Hover entry and exit consumers call the query executor for 5 and 6, respectively. An accepted definition can store an expression or clear it with `$OFF$` and sends no query response. [Query dispatch trace](issue-51-deferred-query-order.md#event-path-and-native-checkpoint) · [Query contract](../ripscrip/5.5-file-transfer-and-queries.md#rip_query).
- **Control bytes.** The second pass at `0x4ad16` enables the ordinary caret/backquote path at `0x4b394`. The default ASCII conversion accepts letters and the specific punctuation in the control table. The original capture gives `5e 40` for caret followed by at-sign and `0d` for `^M`. [Control rules](../ripscrip/5.0-host-commands.md#control-characters) · [Original stages and captures](issue-53-host-control-brackets.md#original-stages-and-first-native-checkpoint).
- **Information and features.** The original ALPHA 4 entries and detailed 3.0 chapters give default product name for `$TERMINFO()$` and a comma-delimited keyword list for `$TERMINFO(LIST)$`. `$IFS(JPEG)$` returns `1` or `0` according to support. Use `$IFS(LIST,_AUDIO)$` for the audio category list. An omitted IFS parameter is an argument error. The index describes the reply types and gives the existing minimal TERMINFO keyword example. List contents and product names come from the responding terminal's advertised features and identity.
