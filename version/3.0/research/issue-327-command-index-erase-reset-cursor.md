- **Wire `e`.** ALPHA 4's explicit color index 0 and its `Uses Back Color: NO` declaration establish the paint source. The #101 erase target trace establishes the bounding rectangle and live-cursor home. Given black graphics palette entry 0, blue STYLE background and red ANSI background, `e` clears black and wire `>` clears blue. The RGB value of entry 0 can be changed. [Erase-source table](../ripscrip/1.4-terminal-ansi-view.md#text-window-erase-sources) · [Draft and original trace](issue-101-extended-text-window-contract.md) · [PR #103](https://github.com/bbs-land/remote-imaging-protocol/pull/103).
- **Wire `*`.** The outer SOFT trace establishes the screen clear, protected-slot exceptions and retained PAL selection. The command index links to the per-family scope. After `!|2A500` and `!|*`, palette 5 is still selected and is now undefined. The exact query result is `5:0`. [Outer SOFT contract](../ripscrip/1.3-world-view-virtual-canvas.md#outer-soft-reset-contract) · [Palette reconciliation](issue-324-palette-reset-selection.md) · [PR #326](https://github.com/bbs-land/remote-imaging-protocol/pull/326).
- **Wire `1c`.** The original setter at `0x3468a` stores numbers below 8. Slot 7 has a visible slashed-circle resource. The protocol range is `00`–`07`. Watch and hourglass retain different logical values when the backend shares their artwork.
