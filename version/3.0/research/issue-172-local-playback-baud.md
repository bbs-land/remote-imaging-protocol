## Live rate and setter grammar

- `context+0x0e` points to the ENV subsystem. There is one live baud dword at subsystem **+0x0c**, separate from the table pointer at **+0x00** and current slot at **+0x0a**. Subsystem initialization zeroes all **0x34** bytes at **0x3d54f**. The record initializer **0x3d5fa** clears individual 16-byte slots through the table pointer. No separate baud setter or field in an ENV record is involved.
- Physical command descriptor **123** (level 3, `e`) selects handler **0x38be1** and a single numeric field with type **2**. The width helper **0x39de0–0x39df6** returns fixed nonnegative types directly. In normal parser state 3, **0x3a919–0x3a96c** converts that field as soon as its allotted digits arrive. Later bytes in the same command do not increase the rate value. The handler respects the usual disabled-graphics flag at **0x38bf9** and writes the decoded integer at **0x38c06**. The inherited draft specifies four characters. Keep that recorded as the draft form, with a separate shipped compatibility width and examples.
- **0x26b5d** sets registration mask 3 and **0x26b85** registers `BAUDEMUL` at name literal **0x7e1c4**, callback **0x30b7c**. Zero parsed arguments returns the live dword via the signed decimal format `%ld` at **0x7ea7c**. Exactly one nonempty decimal argument passes digit validator **0x65589** and decimal conversion **0x68c10**, writes the same dword at **0x30bd4**, and returns an empty insertion. Any other count or a failed digit check sets the callback error flag at **0x30bd9**. There is no `CUR`, per-slot query, two-argument setter or `NONE` branch. Use the ordinary rejected-built-in fallback already documented for 5.2. The portable specification uses nonnegative signed 32-bit values and rejects overflow rather than requiring native wrap.

## ENV selection, ordinary reset and backup

- **0x3dac0–0x3db93** selects/initializes the target record and applies Base Math, RGB precision, coordinate width, WORLD and cursor refresh. It writes the selected index at **0x3db7e** and has no live baud read/write. **0x3dc6c/6d** are RET stubs. **0x30be8–0x30d7c** is COMPAT. Its active setters end with WORLD helper **0x3e9d4**, which writes the current record's dimensions and applies scale through **0x31052**. COMPAT never modifies the live baud dword.
- Bare `*` descriptor **6** invokes **0x1f2f9**, which calls SOFT **0x16220** at **0x1f31b**. ENV defaulting **0x164fe → 0x3d7d1(-2)** clears unprotected records via **0x3d5fa** and marks nonzero slots unused. Selection **0x16508 → 0x3dac0(0)** and subsequent ENV-0 setter calls do not assign the live rate. The outer marker writes at **0x16263/66** target other subsystem members. **0x3c37e** on return marks article state, not playback rate. Neither the ENV index change nor the ordinary whole drawing reset clears the live rate or restarts the byte pacer.
- The ENV backup stream **does include a separate live rate**. Serializer **0x234d2** writes 2-byte selected index at **0x23515**, 4-byte subsystem +0x0c at **0x23552**, then **0x240 = 36 × 16** record bytes at **0x2358d**. Deserializer **0x235da** reads those same fields at **0x2361d**, **0x2365a** and **0x23695**. Its final ENV activation at **0x236d9** leaves the explicitly restored global value in effect. Preserve the ENV backup family's capture of baud, while correcting ownership and distinguishing a slot switch from a backup restore. This qualifies [#142's inherited baud wording](issue-142-env-backup-selection-scope.md) and does not add foreign table selectors.

## File pacer

- Entry **0x2b63/66** caches the rate. Nonzero at **0x2ba2–0x2bc7** calls **0x307f** for bytes per group and **0x322a** for a nominal delay. The inner loop tests live nonzero at **0x2e5f–66**, counts a reader byte before parser routing at **0x2e68**, requests a delay at **0x2e7b** when the counter reaches its group size and then resets the count. A changed nonzero value triggers group/interval recalculation **0x2e89–0x2ec2**. Zero skips the pacing path. An invocation sets up its own grouping; the setting is shared with its caller. Do not promise exact wall-clock throughput.
- Group thresholds from comparisons in **0x307f–0x3229** are exclusive upper bounds. For rates below 500, 1,000, 2,500, 5,000, 7,500, 10,000, 15,000, 20,000, 25,000, 30,000, 40,000, 50,000, 60,000, 75,000, 90,000, 105,000, 130,000, 155,000, 180,000, 250,000, 300,000, 350,000, 400,000, 500,000, 1,000,000, 2,000,000, 4,000,000 or 10,000,000, use the corresponding first group of **3, 5, 7, 10, 13, 15, 20, 25, 30, 33, 40, 50, 60, 75, 90, 105, 130, 155, 180, 250, 300, 350, 400, 500, 1,000, 2,000, 4,000, 10,000**. At and above 10,000,000, use 15,000. Nominal milliseconds at **0x322a** are `floor(floor(163840 × group / rate) × 1000 / 16384)`. Delay helper **0x450d7** polls the system tick until the target. At 2,400 the scheduled delay is 29 ms per seven reader bytes. At 9,600, it is 15 ms per fifteen reader bytes. These are original scheduler parameters, not wire timing deadlines.
- These reads cover local scene playback through the shared file loop. Network receive rate and the independent delay commands/variables keep their existing contracts.
